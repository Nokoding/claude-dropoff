# claude-dropoff

A drop-off for files that are too big to download straight from a Claude chat. Any chat or project can push high quality exports here, then you grab them from the repo.

**Browse everything as scroll pages: https://nokoding.github.io/claude-dropoff/**

Every folder is its own page. A page shows only the images in that folder, stacked top to bottom like a PDF, and a folder with subfolders gets a list of links to them. Share the link for the folder you want to show someone. New folders and images show up on their own after each push.

The pages show web-sized copies so they load fast. The full-size originals are the files in each folder here. Download one and open it at 100% to check the fine detail.

## Folders

| Folder | What is in it |
| --- | --- |
| [senior-spread](https://nokoding.github.io/claude-dropoff/senior-spread/) | Atlanta Adventist Academy yearbook senior spread: backgrounds, borders, SENIORS heading pieces and portrait ring mockups. Details in [senior-spread/README.md](senior-spread/README.md). |

Add a new folder for each project or chat. Use short names with no spaces.
