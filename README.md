# claude-dropoff

Images for the Atlanta Adventist Academy senior yearbook spread.

**View the pages: https://nokoding.github.io/claude-dropoff/**

Every folder is its own page. Each page is just the images, stacked top to bottom, so you scroll like a PDF. Share the link for the section you want to show.

| Section | What is in it |
| --- | --- |
| [Ring mockups v3, frames](https://nokoding.github.io/claude-dropoff/senior-spread/ring-mockups-v3-frames/) | Latest. Wider photos in three frame styles, with the diamond heading and the plain word. |
| [Ring mockups v2](https://nokoding.github.io/claude-dropoff/senior-spread/ring-mockups-v2-big/) | Bigger photos with the text outside each photo. |
| [Ring mockups 14](https://nokoding.github.io/claude-dropoff/senior-spread/ring-mockups-14/) | First ring layout with 14 placeholder portraits. |
| [Heading pieces](https://nokoding.github.io/claude-dropoff/senior-spread/heading-transparent-600dpi/) | SEN, IORS, the diamond and the full word SENIORS as transparent PNGs. |
| [Treering pages with heading](https://nokoding.github.io/claude-dropoff/senior-spread/treering-2241x2900-heading-cinzel/) | Left and right pages at Treering's size, with the Cinzel heading. |
| [Treering pages, metal v2](https://nokoding.github.io/claude-dropoff/senior-spread/treering-2241x2900-metal-v2/) | The pages already uploaded to Treering. |
| [Treering pages, first pass](https://nokoding.github.io/claude-dropoff/senior-spread/treering-2241x2900/) | Plain and sharpened first versions. |
| [Full spread, 600 dpi](https://nokoding.github.io/claude-dropoff/senior-spread/2x-10200x6600-600dpi/) | Background and border at 10200 x 6600. |
| [Full spread, 300 dpi](https://nokoding.github.io/claude-dropoff/senior-spread/1x-5100x3300-300dpi/) | The earlier resolution. |

The pages show web-sized copies so they load fast. The full-size originals are the PNG files in each folder here. Download one and open it at 100% to check the fine detail.

All photos, names, quotes and counts in the mockups are placeholders. Sizes assume a 17 x 11 in spread with no bleed.
